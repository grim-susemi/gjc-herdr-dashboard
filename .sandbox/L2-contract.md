## Workers projection (data/<scopeKey>/workers.json), schema `gjc-herdr-dashboard/workers/1`
```
{ schema, updatedAt:number(ms), empty:boolean, sourceError:string|null,
  cards:[{ id:string, agent:string, title:string /* description ?? task, trimmed, no assignment text */,
           status:'pending'|'running'|'completed'|'failed'|'aborted'|'paused',
           background:boolean, currentTool:string|null, lastIntent:string|null, lastOutput:string|null /* last line of recentOutput */,
           toolCount:number, tokens:number, contextPercent:number|null /* contextTokens/contextWindow*100, null if unknown */,
           cost:number|null /* null = unknown: the host reports 0 for subscription models (K1), so 0 -> null */,
           durationMs:number, retry:{attempt:number|null,delayMs:number|null}|null,
           startedAt:number|null, endedAt:number|null }] /* newest first, at most 50 per scope */ }
```
Never store `assignment`, transcripts, `sessionFile`, args, or any message text beyond `lastIntent`/`lastOutput`/`title`. Sentinel test: an assignment containing `SENTINEL-ASSIGNMENT-7c1` must never appear in the projection or any file.

Bus facts (measured, VERIFICATION.md G5/K1): main bus `pi.events.on(channel, handler)`: `task:subagent:lifecycle` payload `{id, agent, agentSource, description?, status:'started'|'completed'|'failed'|'aborted'|'paused', sessionFile?, index}`; `task:subagent:progress` payload `{agent, agentSource, assignment, index, progress, sessionFile, task}` where `progress` is AgentProgress `{index,id,agent,agentSource,status,task,assignment?,description?,lastIntent?,currentTool?,currentToolStartMs?,recentTools[],recentOutput:string[],toolCount,tokens,contextTokens?,contextWindow?,cost,durationMs,retryState?...}`; `task:subagent:event` carries raw child events (ignore). Match progress to a card by `progress.id` (fallback `agent`+`index`). `ctx.getJobs()` returns `{running:[{id,label,type:'task',status,startTime,endTime,metadata}], recent:[...], delivery}`; jobs with type 'task' whose id is not already a card become `background:true` cards (title = label). Depth > 1 is not visible (README limitation). Handlers only enqueue and are wrapped in try/catch; an exception becomes `sourceError` (shown as the footer's source-error label) and never reaches the host.

## Band layout (src/core/layout.mjs, pure)
`BAND_LAYOUT = {chatShare:0.5, todoHeight:0.35, minTodoRows:8, minLowerRows:12, minWorkersColumns:24, readableWorkersColumns:40}`. Two roles only (Progress is omitted by decision F1): the parent is split right once (Todo keeps the new right half, parent keeps `chatShare`), then the Todo pane is split down with ratio `todoHeight` (the ORIGINAL pane, i.e. Todo, keeps 35% of the rows; the new Workers pane gets 65%). Herdr rounds a split as first child = round(fround(length * fround(ratio))) (copy `childRects`). Floors: Todo rows >= 8, Workers rows >= 12, Workers columns (= dashboard region width) >= 24. Ladder when floors fail: Todo + Workers -> Todo only -> nothing; report `partial:size`. Existing-Todo case: when Todo is already open and Workers is missing, check the floors against the Todo pane's own rect (rows after split: round(h*0.35) >= 8 and h - that >= 12).
Shape check on `herdr pane layout --pane <paneId>` output (`layout.panes[].{pane_id,rect}`, `layout.area`): `isBandShape(layout, ids)` true iff parent.x == area.x, parent.y == area.y, parent.height == area.height, todo.x == parent.x + parent.width, todo.y == area.y, todo right edge == area right edge, workers.x == todo.x, workers.width == todo.width, workers.y == todo.y + todo.height, todo.height + workers.height == area.height. Foreign siblings: any pane in the tab layout that is not the parent, Todo or Workers makes the result `partial:shape` (never close, move, resize or rename foreign panes; our own panes are only closed in the existing O+ T-transitions). Never wait for space.
